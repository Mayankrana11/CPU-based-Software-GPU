### DOOM Setup (Optional)

To experiment with DOOM compatibility, create a `game/doom/` directory in the project root and place your legally obtained DOOM IWAD file (`DOOM.WAD`) and Chocolate Doom installation there. Keep these files local and **do not commit or redistribute them** with this repository.

```text
root/
└── game/
    └── doom/
        ├── DOOM.WAD
        ├── DOOM.EXE
        └── chocolate-doom files
```
